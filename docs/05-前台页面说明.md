## 全局结构

统一包含顶部导航、页面主体和文化资源平台式页脚。导航覆盖：首页、纹样素材、文献资料、共创作品、传承人介绍、应用案例、关于平台。

## 首页

建议结构：主视觉 Banner → 平台与资源数据概览 → 纹样素材精选 → 文献资料 → 共创作品 → 传承人与应用案例 → 平台介绍与页脚。各区块由后台推荐位控制，缺少内容时安全隐藏或显示明确空状态。

### 阶段 6 实现（2026-07-03）

前台首页已经使用 Vue 3 + Vite + TypeScript 独立实现，当前接口映射如下：

- 首屏 Banner：`GET /api/banners`，仅展示后端返回的有效、已上架 Banner。
- 五类推荐资源：`GET /api/featured?limit=8`，按 `pattern、document、creation、inheritor、application_case` 分区呈现。
- 平台简介：`GET /api/pages/about`。
- 盘绣文化介绍：`GET /api/pages/culture`；未发布该页面时显示明确空状态。
- 合作单位：`GET /api/pages/partners`；未发布该页面时显示明确空状态。
- 页脚内容：`GET /api/pages/footer`；接口不可用时保留基础结构和非业务性说明，不伪造合作单位或资源内容。

后台将内容设为 `published` 且开启 `is_featured` 后，内容会进入首页对应推荐区；取消推荐、下架或删除后，公开推荐接口不再返回，前台随接口结果同步消失。Banner 同样由后台状态、排序及有效起止时间控制。

首页各接口均具备加载、空数据和失败状态。推荐接口整体失败时不使用本地数组回退；图片使用原生懒加载、异步解码、失败占位和替代文本。Banner 首图为首屏关键资源，使用 eager 加载。

当前五类正式栏目均已接入真实列表、检索、详情与下载接口，不再使用占位路由。图库、盘绣专题、图案元素、工艺技法不属于当前版本。

## 资源列表与检索

纹样素材、文献资料、共创作品、传承人与应用案例等栏目必须包含：

- 关键词搜索。
- 分类、标签、色彩、工艺、应用部位、寓意筛选。
- 已选条件回显、单项移除和全部重置。
- 综合、最新、最热、下载量排序。
- 结果总数、分页、加载状态、空状态和错误重试。
- URL 查询参数与筛选状态同步，刷新和分享链接后状态可恢复。

不适用某维度的栏目可以隐藏该维度，但接口和交互模式保持统一。

## 资源卡片

图片为视觉主体；显示标题、类型/分类、少量标签或关键属性。有附件时可展示“可下载”标识，但下载主按钮放在详情页。卡片需要统一比例、图片懒加载、占位图、悬停反馈和键盘可访问性。

## 详情页

面包屑 → 主图/图集 → 标题、摘要与元数据 → 正文/文化说明 → 分类、标签和筛选属性 → 来源与版权说明 → 下载区 → 相关资源。仅在存在 `download_file` 时显示下载按钮，点击直接下载。

## 响应式要求

优先保证桌面浏览与管理场景，同时适配平板和手机；筛选区在窄屏可折叠，但已选条件与搜索入口必须清楚可见。

阶段 6 首页在 900px 以下切换为折叠式双列导航与两列资源网格，在 620px 以下切换为单列内容流；Banner 字号、区块间距、文化介绍图文布局、推荐卡片和页脚均随断点调整。移动端菜单触控区域不小于 48px，并保留键盘焦点与“跳至主要内容”入口。

## 阶段 7：检索与详情页面（2026-07-03）

阶段 7 已将五类栏目占位页替换为真实接口页面，并新增关于平台页。五类列表统一请求 `GET /api/contents`，详情统一请求 `GET /api/contents/:type/:id`；路由分别为栏目路径和 `栏目路径/:id`。关于平台读取 `GET /api/pages/about`。

列表页支持关键词、分类、标签、排序和分页；纹样素材额外支持色彩、工艺、应用部位、寓意。筛选状态写入 URL 查询参数，条件、排序或页码变化都会重新请求接口；修改检索条件时自动回到第一页。分类与标签选项分别来自 `/api/categories`、`/api/tags`，扩展筛选由访问者输入真实检索值，不使用前台写死业务数组。页面提供加载、空数据、错误重试、已选条件移除与全部清空状态。

详情页显示主图、纹样多图、标题、简介、正文、标签、类型专属元数据及同类相关推荐。传承人卡片使用人物纵向比例；关于平台使用独立展陈式页面。返回按钮调用浏览器历史返回列表。

下载区严格以详情接口的 `downloadFiles` 数组判断：数组有记录才显示附件与“直接下载”，链接指向 `GET /api/downloads/:id`；无附件时整个下载区不渲染。下载过程没有登录、申请、确认弹窗、订单或支付入口。

首页聚合请求使用独立错误状态，单个统计接口失败不会让整页永久停留在 loading。文化说明缺失时显示空状态或错误状态，不使用静态业务正文冒充后台内容。正文通过服务端白名单清洗并在前台使用 DOMPurify 二次清洗后展示。

响应式断点沿用 900px 与 620px：900px 以下筛选器切换为可折叠面板、详情改为单列；620px 以下资源卡片改为单列，工具栏、元数据和下载区重新排布。

## 阶段 8：视觉收口与联调检查（2026-07-03）

检索页栏目序言新增低对比盘绣几何织纹与边饰，详情页增加极浅档案网格底纹；装饰仅出现在背景层，不承载信息且不影响正文对比度。首页、列表、详情继续统一使用暖纸、深靛蓝、土红与暖金令牌，下载区保持资料附件语义，不使用交易式按钮。

本阶段已完成 frontend TypeScript 与生产构建验证，并在本地浏览器检查首页导航、加载状态和整体视觉。由于当前验收机器没有可调用的 MySQL，真实内容、筛选结果和下载闭环仍需按 `docs/08-测试验收清单.md` 在数据库环境中复验。
