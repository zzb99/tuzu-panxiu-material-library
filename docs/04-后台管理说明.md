# 后台管理说明

## 建设重点

后台负责平台全部内容和公开状态，是本项目优先级最高的业务端。所有内容变化通过本项目数据库与接口同步到前台，不允许维护两份数据。

## 模块

1. 管理员登录。
2. 后台首页 / 数据概览。
3. 首页 Banner 管理。
4. 首页推荐内容管理。
5. 纹样素材管理。
6. 文献资料管理。
7. 共创作品管理。
8. 传承人介绍管理。
9. 应用案例管理。
10. 分类管理。
11. 标签管理。
12. 图片上传。
13. 批量图片上传。
14. PDF / Word 上传。
15. ZIP 素材包上传。
16. 页面内容管理。
17. 网站设置。
18. 管理员账号管理。

## 内容编辑要求

统一支持标题、摘要、正文、封面、图集、分类、标签、色彩、工艺、应用部位、寓意、来源/版权说明、排序、推荐、SEO 信息、下载附件和发布状态。不同类型可显示扩展字段，但基础交互保持一致。

状态至少包含草稿、已上架、已下架；新建默认草稿。列表支持关键词、类型、分类、状态、时间筛选及批量上下架。删除默认软删除，关键操作写入审计日志。

## 上传要求

- 支持单图、批量图片、PDF、Word（DOC/DOCX）和 ZIP。
- 展示上传进度、成功/失败结果、文件大小与类型。
- 服务端再次校验类型、扩展名、大小、文件名和路径。
- 上传完成后由管理员明确选择文件角色；`download_file` 决定前台下载入口。

## 权限初版

初版只设管理员角色，但账号必须独立、密码加密存储、禁用状态有效、登录受 JWT 保护。后续若引入细粒度权限，需先扩充文档与数据模型。

## 阶段 4：后台基础框架（已完成）

管理后台位于 `admin/`，技术栈为 Vue 3、Vite、TypeScript 与 Element Plus。当前阶段完成可运行框架，不在页面中填充静态业务假数据。

### 登录与请求

- 登录页：`/login`，对接 `POST /api/admin/auth/login`。
- 登录成功后将 JWT 保存到浏览器 `localStorage` 的 `tuzu_panxiu_admin_token`。
- Axios 请求封装会给所有后台请求自动添加 `Authorization: Bearer <token>`。
- 接口地址只从 `VITE_API_BASE_URL` 读取；缺少变量时应用会明确报错，不使用代码内备用地址。
- 401 响应会清理 token、跳回登录页并提示登录失效；其他接口错误统一使用 Element Plus 消息提示。
- 路由守卫会拦截未登录访问；已登录访问 `/login` 会转到 `/dashboard`。
- 顶部管理员信息通过 `GET /api/admin/auth/profile` 获取，退出登录会清理 token。

### 页面与菜单

后台首页为 `/dashboard`，通过真实后台列表接口汇总五类内容、分类、标签和 Banner 数量。接口未启动或部分请求失败时显示可识别的错误提示，不伪造统计数字。

左侧菜单包含：首页概览、Banner 管理、首页推荐、纹样素材、文献资料、共创作品、传承人介绍、应用案例、分类管理、标签管理、页面内容、网站设置、管理员管理。图库、盘绣专题、图案元素、工艺技法不属于当前版本。

后台未包含普通用户、订单、支付、发票、会员、评论、授权申请或下载审核菜单。

### 通用组件

- `ImageUploader.vue`：对接 `/api/admin/uploads/image`，支持类型、大小检查和进度。
- `FileUploader.vue`：可按 `pdf`、`word`、`zip`、`file` 类型调用真实上传接口。
- `RichTextEditor.vue`：支持标题、粗体、斜体、列表、链接与清除格式，使用 `v-model` 输出 HTML。
- `EmptyState.vue`、`LoadingState.vue`：统一空状态和加载状态。

### 本地启动

复制 `admin/.env.example` 为 `admin/.env`，按实际后端地址设置 `VITE_API_BASE_URL`（默认示例为 `http://localhost:3000/api`），然后执行：

```powershell
cd admin
pnpm install
pnpm dev
```

默认访问 `http://localhost:5174/login`。联调前需先启动后端和 MySQL。

### 当前完成状态

五类业务模块的数据表格、检索、分页、编辑、上下架、删除、排序、推荐和附件绑定均已接入真实接口。网站设置支持站名、副标题、联系方式、版权和备案信息；管理员管理支持新增、启停及当前账号改密。完整上传、下载和逐模块写入闭环仍须按验收清单进行真实数据回归。

## 阶段 5：admin 后台内容管理（2026-07-03）

### 已接入真实接口

- 五类内容统一使用 `/api/admin/contents` 完成真实分页、关键词/状态/分类筛选、排序、新增、编辑、删除、草稿、上下架、排序和首页推荐。
- 表单按照后端 `ContentBodyDto` 与各内容表白名单显示差异字段，不向接口发送类型不支持的字段。
- 封面上传接入 `/api/admin/uploads/image`，附件接入 PDF、Word、ZIP、通用文件上传，并在内容首次保存后通过 `/api/admin/download-files` 建立真实附件关系。
- 纹样详情图接入 `/api/admin/uploads/images` 与 pattern image 接口，支持批量上传、预览、顺序更新和删除。新增内容须先保存草稿取得资源 ID，再绑定详情图。
- Banner、分类、标签、页面内容分别接入 `/api/admin/banners|categories|tags|pages` 的真实分页与 CRUD。
- 首页推荐页汇总五类内容接口中 `is_featured` 的真实记录，各内容列表可直接开关推荐状态。
- 所有删除均有确认提示，保存、上传、状态、排序、推荐操作均有成功/失败反馈；失败消息由统一 Axios 拦截器展示。

### 字段对应

- 通用：`title/coverImage/categoryId/description/content/tags/status/sortOrder/isFeatured` 对应数据库 snake_case 同名字段。
- 纹样：`sourceArea/applicationPart/craftType/mainColors/meaning`。
- 文献：`author/source/year/summary`。
- 共创：`creatorName/creationDate`；传承人：`level/region/birthYear`；案例：`caseType/clientName/caseDate`。

### 当前接口制约

- 网站设置已经接入 `GET/PUT /api/admin/site-settings`，前台页头和页脚读取公开设置接口。
- 共创图集、传承人代表作品、案例相关纹样与图集等没有对应 DTO、表字段或关系维护接口，本阶段未伪造实现。
- 当前只有纹样拥有正式多图关系接口；其他内容类型可上传封面和下载附件，但不能可靠维护独立多图关系。
- 管理员账号管理只面向 CMS 管理员，不得扩展为普通用户体系；当前支持新增、启停和当前管理员改密。

### 验证

```powershell
cd admin
pnpm typecheck
pnpm build
pnpm dev
```

联调时启动 MySQL 与 backend，登录后在任一内容模块新增草稿、编辑并上架；确认后台列表状态改变，再请求公开 `/api/contents?type=对应类型`。下架后再次请求，记录应消失。附件绑定成功后可用 `/api/downloads/:id` 直接下载。
