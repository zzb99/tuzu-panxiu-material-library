# 视觉风格规范

## 首页主视觉

首页使用 `frontend/public/images/panxiu-hero-dark.png` 作为固定首屏背景。标题、搜索框与素材统计叠加在同一张沉浸式背景上，不再使用动态拼贴墙。

桌面端主导航紧跟品牌标志左对齐排列，不使用自动右对齐产生大面积中部空白；900px 以下仍切换为折叠菜单。

## 滚动条

前台使用 7px 细滚动条。轨道固定为暖黑色，避免内页出现浏览器默认白色轨道；滑块采用低饱和金色，悬停时提高亮度。Firefox 使用同等的细滚动条设置；不隐藏滚动能力，以保留鼠标拖动和键盘可访问性。

## 深色基调

全站页头、页脚、深色按钮与滚动轨道统一使用暖黑和炭褐，不再使用偏蓝的深靛青。暗金用于边线和状态强调，盘绣红仅用于搜索、主要操作与少量视觉焦点。

## 统一组件令牌

- 内容最大宽度：`1240px`，桌面两侧留白 `32px`，移动端留白 `14px`。
- 圆角：小控件 `8px`、普通卡片 `14px`、重点展陈区 `22px`。
- 阴影：默认使用低透明暖灰阴影；悬停时只增加高度和清晰度，不使用强发光。
- 卡片：统一为暖米白博物馆卡片，边框使用低透明暖灰，图片保持固定比例并使用 `object-fit`。
- 按钮：主要操作使用盘绣红，次要操作使用暖白底和细边框，链接型操作使用暗金反馈。
- 动效：卡片悬停上浮不超过 `6px`，图片缩放约 `1.035`；遵循 `prefers-reduced-motion`。

## 列表与详情

列表页使用独立栏目背景、圆角搜索栏、吸顶筛选卡片、统一工具栏和胶囊分页按钮。详情页使用大图展陈区、可读标题区、结构化信息卡、正文区、暖黑下载面板和相关资源卡片。字符串与 JSON 两种标签格式均应正确呈现。

## 响应式断点

- `1180px`：缩小导航与卡片列数。
- `900px`：导航切换为折叠菜单，列表筛选切换为展开按钮，详情页改为单列。
- `620px`：首页统计使用两列，列表卡片和详情信息改为单列，页脚改为纵向布局。

## 风格定位

整体气质为“庄重、温润、开放、现代的民族文化数字资源平台”。借鉴数字文化遗产平台的留白、展陈感和内容优先原则，结合土族盘绣的色彩、针法与几何秩序形成原创视觉系统。

## 色彩建议

- 主色：从盘绣常见深红、靛青中提炼，正式设计阶段通过真实素材校准。
- 背景：暖白、浅米灰，避免大面积纯白造成生硬感。
- 正文：近黑色；次级文字使用中性灰，保证对比度。
- 点缀：少量金黄、青绿或玫红，只用于状态、标签和重点动作。
- 色彩筛选项必须同时显示色块与文字，不依赖颜色单独传达信息。

## 排版与版式

中文标题可使用具有文化感的展示字体，但正文和后台使用清晰的系统无衬线字体。首页采用宽幅展示与稳定网格；列表卡片图片比例统一；详情页控制正文行宽。所有尺寸后续沉淀为设计令牌，禁止页面随意生成相近值。

## 组件原则

- 导航简洁稳定，当前栏目状态明确。
- 卡片边界克制，以图片、留白和轻微阴影/描边建立层级。
- 筛选器强调可扫描性，选择、禁用、清除状态完整。
- 主按钮只突出关键动作；下载按钮清晰但不使用交易化文案。
- 动效短促、自然，尊重系统“减少动态效果”设置。

## 图片与图形

优先使用授权清晰、色彩准确的盘绣素材。裁切不得破坏纹样主体；缩略图与原图分开管理。图标使用统一原创或开源图标系统，不截取参考站图标或视觉资产。

## 可访问性

正文和控件满足基本对比度；交互元素具备键盘焦点；图片提供替代文本；表单错误不能只靠颜色表达；移动端触控区域足够大。

## 阶段 6 前台设计令牌与首页应用

首页采用原创的“暖纸展陈 + 深靛蓝文化叙事”视觉系统，不复用参考站源码或视觉资产：

- 背景：暖纸色 `#F5F1E9`、深一层纸色 `#EBE4D7`、内容白 `#FFFDF8`。
- 主色：深靛蓝 `#142F3B`，用于导航、文化介绍和页脚。
- 强调色：土红 `#8D2F31` 与暖金 `#B79050`，仅用于眉题、关键状态和细节边饰。
- 正文：近墨黑 `#1D2425`；次级文字 `#6E716D`。
- 内容宽度：桌面最大 `1240px`，常规左右安全边距 `32px`；手机安全边距 `14px`。

首屏使用宽幅影像、靛蓝渐变遮罩、宋体文化标题和克制的几何盘绣边饰；首页区块以 72–110px 的纵向留白建立数字展陈节奏。资源卡片按模块采用四列、专题双列、文献三列和人物纵向比例等不同编排，但统一使用轻描边、短促悬停和稳定图片比例。

所有装饰纹样由 CSS 几何图形原创生成，不承载业务信息，不影响文字阅读。图片加载失败时展示中性织物色几何占位，不使用未经授权的默认图片。动效遵循 `prefers-reduced-motion`，键盘焦点使用暖金描边。

## 阶段 7 检索与详情视觉规范

- 检索页采用“深靛蓝栏目序言 + 暖纸色档案工作台”结构，搜索框作为首要操作，左侧筛选与右侧结果形成清晰的资料库工作区，而非商城货架。
- 筛选选中状态使用低饱和土红底色与描边；色彩筛选同时保留文字，不用色块单独表达含义。排序、分页和错误重试均使用中性功能控件。
- 资源卡片统一以影像为主体，使用克制边框、短促抬升和宋体标题；传承人使用 3:4 人物比例，其余默认 4:3。卡片不出现价格、购买或交易文案。
- 详情页采用大幅主视觉与独立信息栏，元数据以展签式网格呈现，正文最大阅读宽度约 850px。专题详情将封面扩展为宽幅并突出导读，区别于普通内容详情。
- 下载区使用深靛蓝底与暖金动作文字，文案固定强调“直接下载”，不使用购买按钮样式。无附件时不保留空下载占位。
- 移动端筛选折叠但搜索入口、当前条件数量和排序始终可见；卡片、详情、元数据和下载区在 620px 下均为单列。

## 阶段 8 视觉收口

- 检索页深靛蓝序言区使用低透明度菱形交织纹，仅在右侧渐显，避免与标题和说明争夺注意力。
- 详情页使用 32px 极浅档案网格增强资料库阅读氛围；正文仍置于清晰内容层，阅读宽度与对比度不变。
- 视觉验收以真实接口状态为准；接口不可用时保留明确加载/失败反馈，不用静态内容制造“已完成”效果。
