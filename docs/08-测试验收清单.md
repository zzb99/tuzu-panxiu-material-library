## 当前剩余风险

- MySQL 8.4.9 已安装，数据目录位于 `D:\MySQL\data`。当前进程无管理员提升权限，MySQL 未注册为 Windows 服务；电脑重启后需双击根目录 `启动项目.cmd`。
- seed 中的媒体路径只用于接口联调；对应真实文件未必存在，需通过后台上传授权清晰的本地素材。
- admin 构建产物主包较大（Element Plus），不影响本地功能，但后续可按路由继续拆包。
- 本机 5173/5174 可能被其他服务占用；本阶段浏览器检查使用了临时端口，默认端口行为仍由 Vite 配置确定。
