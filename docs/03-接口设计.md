# 接口设计

## 1. 基础约定

- 基础路径：`/api`，JSON 使用 UTF-8，分页从 1 开始。
- 成功响应：`{ "code": 0, "message": "success", "data": ... }`。
- 失败响应：`{ "code": HTTP状态码, "message": "错误说明", "data": null }`。
- 参数校验会剔除未声明字段并拒绝额外字段；服务端错误不返回堆栈、数据库信息或磁盘绝对路径。
- CORS 已开启；管理端可携带 `Authorization` 请求头。
- `UPLOAD_DIR` 指向的目录以 `/uploads/` 提供静态访问；相对路径统一按项目根目录解析。上传与下载接口已在文件管理模块实现。

## 2. 环境变量

后端从项目根目录或 `backend/` 下的 `.env` 读取：

`DATABASE_HOST、DATABASE_PORT、DATABASE_USER、DATABASE_PASSWORD、DATABASE_NAME、BACKEND_PORT、JWT_SECRET、UPLOAD_DIR、MAX_UPLOAD_SIZE`。

TypeORM 使用现有 MySQL 表结构，`synchronize` 固定关闭，后端不会自动修改数据库结构。
`MAX_UPLOAD_SIZE` 可写为纯字节数，也可写为 `50mb`、`1gb` 等带单位格式。

## 3. 管理员认证

### `POST /api/admin/auth/login`

只用于 `admin_user` 管理员登录，不存在普通用户登录。

请求：

```json
{ "username": "admin", "password": "password" }
```

成功时 `data.token` 返回有效期 8 小时的 JWT，同时返回不含密码哈希的管理员基本信息。密码使用数据库中的 bcrypt 哈希比对；禁用管理员不能登录。

### `GET /api/admin/auth/profile`

请求头：`Authorization: Bearer <token>`。用于验证 token 和获取当前管理员；缺少、无效或对应管理员已禁用时返回 401。

## 4. 内容列表与检索

### `GET /api/contents`

公开真实数据库查询，不需登录，并在服务端强制附加 `status = 'published'`。客户端不能用参数绕过；`draft` 和 `offline` 不会返回。

### `GET /api/admin/contents`

必须携带管理员 JWT。可查看全部状态，也可通过 `status=draft|published|offline` 过滤。

两条接口当前都要求 `type`：`pattern、document、creation、inheritor、application_case`。

公共参数：

- `page`：默认 1；`pageSize`：默认 20，最大 100。
- `keyword`：匹配 `title` 和 `description`。
- `categoryId`：分类 ID。
- `tags`：可重复传入，如 `tags=吉祥&tags=动物`；同维度取交集。
- `sort`：`default、latest、popular、downloads`。
- 仅纹样支持 `colors、crafts、parts、meanings` 多值筛选；其他类型传入这些参数会返回 400。

分页结果：

```json
{ "items": [], "page": 1, "pageSize": 20, "total": 0, "totalPages": 0 }
```

## 5. 状态与安全边界

- 公开接口的 published 限制由后端固定施加，不信任前端传参。
- 管理内容接口统一使用 JWT 守卫；后续新增、编辑、删除、上下架接口也必须复用该守卫。
- 内容类型、状态和排序均使用白名单，查询值通过参数绑定进入 MySQL。
- 数据库密码和 JWT 密钥只从环境变量读取，不写入代码。

## 6. 阶段 3：内容管理接口（已实现）

五类内容的 `type` 为：`pattern`、`document`、`creation`、`inheritor`、`application_case`。所有接口直接读写 MySQL；字段使用 camelCase 入参、数据库字段原名出参。

- `GET /api/contents?type=pattern`：公开列表，只返回 `published`。支持 `keyword`、`categoryId`、重复 `tags`、`page`、`pageSize`、`sort=default|latest|popular|downloads`；纹样额外支持重复 `colors`、`crafts`、`parts`、`meanings`。
- `GET /api/contents/:type/:id`：公开详情，只能读取已上架内容；纹样附带 `images`，所有详情附带 `downloadFiles`。
- `GET /api/featured?type=pattern&limit=8`：首页推荐；只返回 `published AND is_featured=1`。不传 type 时按五类分组返回。
- `GET /api/admin/contents`、`GET /api/admin/contents/:type/:id`：后台列表、详情。
- `POST /api/admin/contents/:type`、`PUT|DELETE /api/admin/contents/:type/:id`：新增、编辑、删除。
- `PATCH /api/admin/contents/:type/:id/status`：请求体 `{"status":"draft|published|offline"}`，负责草稿、上架、下架。
- `PATCH /api/admin/contents/:type/:id/sort`：请求体 `{"sortOrder":10}`。
- `PATCH /api/admin/contents/:type/:id/featured`：请求体 `{"isFeatured":true}`。
- `POST /api/admin/patterns/:patternId/images`、`PUT|DELETE /api/admin/pattern-images/:id`：纹样多图管理。

除登录和公开接口外，上述 `/api/admin/**` 均要求 `Authorization: Bearer <JWT>`。

## 7. Banner、分类、标签与页面内容

- 公开：`GET /api/banners`、`GET /api/categories`、`GET /api/tags`、`GET /api/pages/:key`。统一只返回 `published`；Banner 还会检查有效起止时间。
- 后台：`/api/admin/banners`、`/api/admin/categories`、`/api/admin/tags`、`/api/admin/pages`，提供分页列表和 `POST` 新增、`PUT /:id` 编辑、`DELETE /:id` 删除。
- 后台列表支持 `keyword`、`status`、分页；分类额外支持 `resourceType`。

## 8. 上传与文件记录

所有上传接口要求管理员 JWT，字段名为 `file`，批量图片字段名为 `files`：

- `POST /api/admin/uploads`：通用单文件。
- `POST /api/admin/uploads/image|pdf|word|zip|video|file`：按类型上传。
- `POST /api/admin/uploads/images`：批量图片，最多 20 个。
- `GET /api/admin/media-files?page=1&pageSize=20&type=image`：查询 `media_file`。

允许扩展名：jpg、jpeg、png、webp、svg、pdf、doc、docx、zip、mp4。服务端同时校验文件签名、SVG 危险内容和大小；单文件写盘前硬限制为 50MB。其他扩展名或伪装文件会被拒绝。成功响应包含 `file_url`、`file_name`、`file_size`、`file_type` 等数据库真实记录，不返回磁盘绝对路径。`DELETE /api/admin/media-files/:id` 仅允许删除未被内容引用的媒体文件。

## 9. 下载附件与直接下载

- `POST /api/admin/download-files`：新增附件，使用 `resourceType`、`resourceId`、`mediaFileId`、`fileName`。
- `PUT|DELETE /api/admin/download-files/:id`：替换或删除附件记录。
- `GET /api/admin/download-files/:type/:resourceId`：后台查询附件。
- `GET /api/download-files/:type/:resourceId`：公开查询，仅已上架资源可访问。
- `GET /api/downloads/:id`：公开直接返回文件，无登录、申请、审核、订单或支付；成功请求会同时增加附件与资源的 `download_count`。

## 10. 网站设置、管理员与接口文档

- `GET /api/site-settings`：公开读取站名、副标题、联系方式、版权和备案信息。
- `GET|PUT /api/admin/site-settings`：管理员读取和保存网站设置。
- `GET|POST /api/admin/admin-users`、`PUT /api/admin/admin-users/:id`：管理员列表、新增和启停；不能禁用当前账号或最后一个可用管理员。
- `PATCH /api/admin/auth/password`：当前管理员校验原密码后修改密码。
- `GET /api/docs`：Swagger/OpenAPI 页面。

登录接口限制为每分钟 5 次；其他接口默认每分钟 120 次。CORS 只接受 `CORS_ORIGINS` 配置的来源。
