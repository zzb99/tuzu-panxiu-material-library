# 本地运行与联调说明

## 1. 启动前检查

1. Node.js LTS（建议 20 或 22）、pnpm 9+、MySQL 8.0+ 可从终端调用。
2. 根目录 `.env` 已填写真实 MySQL 连接和随机 `JWT_SECRET`。
3. `admin/.env`、`frontend/.env` 的 `VITE_API_BASE_URL` 为 `http://localhost:3000/api`。
4. 根目录 `uploads/` 存在且当前用户可写。

## 2. 首次初始化

```text
pnpm --dir backend install
pnpm --dir admin install
pnpm --dir frontend install
```

然后初始化数据库（以下重定向命令适合 `cmd.exe`；PowerShell 7 请使用下方 `SOURCE` 方式）：

```text
mysql -u root -p < database/schema.sql
mysql -u root -p tuzu_panxiu < database/seed.sql
```

```sql
SOURCE D:/桌面/tuzu-panxiu-material-library/database/schema.sql;
SOURCE D:/桌面/tuzu-panxiu-material-library/database/seed.sql;
```

数据库脚本顺序不能颠倒。`schema.sql` 会重建项目表，不用于保留数据的升级场景。

## 3. 启动与地址

依次启动 MySQL、backend、admin、frontend：

```powershell
pnpm --dir backend start:dev
pnpm --dir admin dev
pnpm --dir frontend dev
```

访问前台 `http://localhost:5173`、后台 `http://localhost:5174/login`、接口 `http://localhost:3000/api`。默认管理员为 `admin / password`。

## 4. 最小联调闭环

1. 登录后台，上传一张图片并创建一条纹样草稿。
2. 编辑内容、设置封面和筛选字段，切换为“已上架”；前台纹样列表应出现该记录。
3. 修改标题并保存；刷新前台详情，标题应更新。
4. 上传 PDF、Word 或 ZIP，并绑定为该记录的附件；详情页应出现“直接下载”。
5. 点击附件，应直接返回正确文件，不出现登录、申请或确认弹窗。
6. 将记录下架；前台列表不再返回，旧详情地址应返回不可用。
7. 设置“首页推荐”；仅已上架且推荐的记录应出现在首页。

## 5. 数据库快速检查

```sql
USE tuzu_panxiu;
SHOW TABLES;
SELECT username, status FROM admin_user;
SELECT id, title, status, is_featured FROM pattern;
SELECT resource_type, resource_id, file_url FROM download_file;
```

预期共 14 张表，公开接口只返回 `published` 内容。

## 6. 常见问题

- 数据库报错：核对 `.env`、字符集、MySQL 版本和导入顺序。
- 端口冲突：Vite 可用 `-- --port 新端口`；后端修改 `BACKEND_PORT` 后同步更新两个 `VITE_API_BASE_URL`。
- 上传后找不到文件：检查 `uploads/` 权限，并确认数据库保存的是 `/uploads/...` 相对 URL。
- 接口有数据但前台无内容：确认状态为 `published`；首页还要求 `is_featured=1`。
- 下载区缺失：只有真实 `download_file` 关系会触发下载区，普通封面或媒体上传不会自动成为下载附件。
- 页面显示接口错误：不要用本地静态数组替代；先查看 backend 终端与浏览器网络请求定位真实问题。
