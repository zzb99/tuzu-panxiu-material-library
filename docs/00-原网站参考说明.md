# 原网站参考说明

## 参考对象与目的

本项目高度参考[数字敦煌开放素材库](https://ip.e-dunhuang.com/)的公开前台体验，用于确定数字文化资源平台的信息层级、内容浏览节奏与视觉气质。参考只限产品体验与公开页面观察，不构成代码或数据复用。

## 必须参考的体验

1. 高度参考原网站首页布局：主导航、视觉引导、资源概览、分栏目推荐、专题内容与平台说明形成连续浏览叙事。
2. 高度参考原网站素材库检索体验：检索入口醒目，筛选条件清楚，结果区支持组合筛选、排序、分页、条件回显与重置。
3. 高度参考原网站资源卡片样式：以高质量图片为主体，标题和关键元数据层级清晰，悬停反馈克制，卡片密度适合文化资源浏览。
4. 高度参考原网站详情页结构：主视觉、标题与元数据、内容说明、标签、关联资源和附件下载各司其职。
5. 高度参考原网站专题页组织方式：专题拥有独立封面、导语、内容章节和关联资源集合，而不是普通标签结果页。
6. 高度参考原网站数字文化资源平台气质：庄重、雅致、留白充分，强调文化内容本身，并兼顾现代数字产品的清晰与效率。
7. 不直接复制原站代码，而是用全新代码复刻体验；页面组件、样式、接口、后台、数据库与文件存储均由本项目独立开发。

## 本项目的差异边界

- 内容主题替换为土族盘绣纹样、工艺、文献、传承人与应用案例。
- 不接入参考站接口、后台、数据库、账号或任何私有资源。
- 不复用参考站压缩 JS、CSS、HTML、线上打包产物或受限素材。
- 不实现用户中心、购物交易、授权申请、审核下载与区块链证书。
- 下载采用“后台有附件则前台直接下载”的最短路径。

## 实施原则

后续设计应先提炼“结构、比例、节奏、交互模式”，再结合土族盘绣文化特征建立原创组件和视觉系统。素材版权、来源与授权信息必须由本项目自行维护。
