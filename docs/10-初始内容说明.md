# 初始内容说明

## 内容范围

本轮仅为现有五个资源模块填充可运行的初始内容：纹样素材、文献资料、共创作品、传承人介绍、应用案例。图库、专题、图案元素、工艺技法不属于当前版本，未创建数据表、接口或伪装记录。

本地原创占位封面位于 `uploads/placeholders/`。`material-readme.txt` 只用于验证直接下载，不是正式授权素材。封面图不自动作为下载附件；只有 `download_file` 表中明确绑定的资源才显示下载入口。

## 基础事实范围

种子数据只将资料包提供的以下内容作为基础事实：

- 土族盘绣是中国国家级非物质文化遗产代表性项目。
- 项目类别为传统美术，项目编号为Ⅶ—24，申报地区为青海省互助土族自治县。
- 土族主要聚居于青海省东部地区，互助土族自治县是重要聚居地之一。
- 李发秀对应的代表性项目为土族盘绣，类别为传统美术，地区为青海省互助土族自治县。
- 平台定位为“土族盘绣纹样开放素材库”，可从纹样、色彩、针法、服饰应用、图案寓意和数字化采集等角度整理资源。

其余纹样名称、寓意、资料条目、共创作品和应用案例均明确写为示例、整理说明或待补充内容，不作为权威史实或真实商业案例。

## 重新初始化

初始化环境可依次执行：

```powershell
mysql -u root -p < database/schema.sql
mysql -u root -p tuzu_panxiu < database/seed.sql
```

PowerShell 无法使用 `<` 时，在 MySQL 客户端执行：

```sql
SOURCE D:/桌面/tuzu-panxiu-material-library/database/schema.sql;
SOURCE D:/桌面/tuzu-panxiu-material-library/database/seed.sql;
```

`schema.sql` 会删除并重建项目表。仅在允许清空旧数据的初始化环境中使用；已有需保留的数据时，不应执行 schema，而应通过后台录入或另写迁移脚本。

已有数据库需要保留原内容时，可运行增量同步脚本：

```powershell
node scripts/sync-initial-content.js
```

脚本会在临时数据库校验 `schema.sql` 与 `seed.sql`，再按标题、页面键和 slug 合并内容，不会清空现有资源；同步结束后会删除临时数据库。

## 上线前人工替换

- 用来源明确、获得授权的实物照片替换全部 SVG 占位封面。
- 为纹样补充采集编号、真实应用部位、经核校的寓意说明、来源记录与授权状态。
- 为文献条目补充真实文件、作者、出版或整理来源；平台自建条目不得冒充论文。
- 为传承人资料补充经核验的介绍和获得授权的肖像；“待补充”记录应替换或下架。
- 为共创作品和应用案例补充真实作者、项目过程、署名和授权信息。
- 将 `material-readme.txt` 替换为各资源真实且可公开下载的附件，并填写正确文件大小。
- 在后台补充联系方式和备案信息，并核定最终版权与素材使用说明。
