# 项目总说明

## 建设目标

建设一套本地可运行、内容可持续维护的“土族盘绣纹样开放素材库”。管理员通过独立后台维护内容与附件；前台自动展示已上架资源，并提供多条件检索、详情浏览和免登录直接下载。

## 用户角色

- 访客：浏览、检索、查看详情、直接下载已有附件。
- 管理员：登录后台，维护内容、分类、标签、页面、推荐位、网站设置和管理员账号。

不存在普通用户账号体系。

## 前台栏目

首页、纹样素材、文献资料、共创作品、传承人介绍、应用案例、关于平台。

## 后台范围

管理员登录、数据概览、Banner、首页推荐、各前台内容类型、分类、标签、单图与批量图片上传、PDF/Word/ZIP 上传、页面内容、网站设置、管理员账号管理。

## 核心业务闭环

管理员创建或修改内容 → 上传封面/图集/下载附件 → 设置分类标签及检索属性 → 上架 → 前台公开接口返回最新内容 → 访客检索并查看详情 → 有附件时直接下载并累计次数 → 管理员下架后前台立即不可见。

## 非目标

普通用户注册登录、用户中心、收藏/我的素材、购物车、订单、支付、发票、会员、评论、在线授权申请、下载审核、区块链证书均不建设。

## 阶段建议

1. 基础设计与工程初始化。
2. 数据库、接口、上传和管理员鉴权。
3. 管理后台内容闭环。
4. 前台首页、检索、详情、专题和下载。
5. 内容导入、联调、性能与验收。
