# 纹样命名库导入说明

## 导入方式

确保 MySQL 已启动且 `database/schema.sql` 已导入，然后在项目根目录执行：

```powershell
pnpm import:patterns
```

脚本扫描 `土族盘绣纹样命名/纹样/`，将 PNG 复制到 `uploads/pattern-naming-library/`，按上级文件夹创建纹样分类，并写入已上架的纹样、详情图、媒体文件与直接下载关系。

脚本可重复执行，已导入的图片不会重复建立纹样记录。原资料未提供的寓意、年代、来源地和版权信息保持“待核校”，需继续在后台补充。

## 字段映射

- 上级文件夹：纹样分类与标签。
- 文件名：纹样标题；只有页码时使用“分类（页码）”作为保守标题。
- PNG：封面图、详情图和免登录直接下载原图。
- `craft_type`：土族盘绣。
- 资料中没有的字段：不猜测，在正文中标记待核校。
